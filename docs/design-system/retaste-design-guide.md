# Re:Taste 디자인 가이드

이 문서는 Re:Taste의 사용자 화면과 어드민 화면을 새로 만들거나 수정할 때 사용하는 기준이다. 실제 구현의 기준 파일은 `app/styles/design-system.css`이며, 이 문서의 토큰명은 CSS와 동일하게 유지한다.

## 1. 디자인 원칙

1. 음식과 취향이 가장 먼저 보인다. 장식보다 장소명, 취향 배지, 추천 이유의 위계를 우선한다.
2. 크림색 바탕, 깊은 녹색, 라임 신호색을 유지한다. 신호색은 핵심 선택과 상태에만 제한한다.
3. 사용자 화면은 여유롭게, 어드민은 촘촘하게 구성하되 동일한 컨테이너와 간격 체계를 쓴다.
4. 한 화면에서 임의의 여백 값을 늘리지 않는다. 아래 간격 토큰 중 가장 가까운 값을 사용한다.
5. 모서리를 모두 pill로 만들지 않는다. 카드, 컨트롤, 배지가 맡은 역할에 맞는 반경을 사용한다.

## 2. 브랜드 기반

### 색상

| 역할 | 토큰 | 기본값 | 사용처 |
|---|---|---:|---|
| 페이지 배경 | `--surface-page` | `#f3f4ed` | 전체 배경 |
| 카드 배경 | `--surface-card` | `#ffffff` | 카드, 입력 영역 |
| 본문 잉크 | `--color-ink` | `#17221c` | 제목, 본문, 핵심 선 |
| 브랜드 강조 | `--color-accent` | `#2d674d` | 링크, 선택, 정보 배지 |
| 신호색 | `--color-signal` | `#e7ff55` | 대표 선택, 핵심 CTA |
| 경계선 | `--color-line` | `#c8cdc2` | 카드와 섹션 구분 |

위험, 성공, 경고의 의미색은 기존 기능 색을 유지한다. 신호색을 오류나 경고 의미로 사용하지 않는다.

### 글꼴

- 제목과 본문: `SUIT`, `Pretendard`, `Apple SD Gothic Neo`, `Noto Sans KR`, system sans-serif 순서
- 영문 eyebrow, 수치, 상태 코드: `IBM Plex Mono`
- 큰 제목은 굵기 900, 본문은 400~600을 기본으로 한다.
- 한글 제목의 자간은 촘촘하게 쓰되 본문에는 과한 음수 자간을 적용하지 않는다.
- 본문 줄 높이는 `--line-height-body`(1.6), 한글은 `word-break: keep-all`을 기본으로 한다. 긴 URL 등은 줄바꿈해 가로 넘침을 막는다.
- 보조 문구도 `--font-size-label`(12px)보다 작게 표시하지 않는다. 모바일 핵심 버튼·필터·시트 손잡이는 최소 44px 조작 높이를 확보한다.

## 3. 레이아웃과 간격

### 컨테이너

| 항목 | 토큰 | 값 |
|---|---|---:|
| 최대 콘텐츠 폭 | `--layout-max` | `1280px` |
| 데스크톱 좌우 거터 | `--layout-gutter` | `20px` |
| 모바일 좌우 거터 | `--layout-gutter-mobile` | `14px` |
| 사용자 페이지 시작 | `--page-start-user` | `64px` / 모바일 `32px` |
| 어드민 페이지 시작 | `--page-start-admin` | `48px` / 모바일 `28px` |

페이지 최상단은 사용자 화면에서 `.course-page`, `.discovery-page`, `.member-hub` 패턴을 따른다. 어드민의 새 화면은 최상위에 `.admin-page`, 폭을 제한할 요소에 `.admin-page-frame`을 추가한다.

### 간격 스케일

| 토큰 | 값 | 대표 사용 |
|---|---:|---|
| `--space-1` | 4px | 미세 정렬 |
| `--space-2` | 8px | 작은 요소 사이 |
| `--space-3` | 12px | 표 셀, 조밀한 컨트롤 |
| `--space-4` | 16px | 기본 내부 간격 |
| `--space-5` | 20px | 모바일 카드 패딩 |
| `--space-6` | 24px | 어드민 패널, 폼 그룹 |
| `--space-8` | 32px | 데스크톱 카드 패딩 |
| `--space-12` | 48px | 히어로 하단, 어드민 섹션 |
| `--space-14` | 56px | 모바일 주요 섹션 |
| `--space-16` | 64px | 페이지 시작 |
| `--space-20` | 80px | 사용자 주요 섹션 |
| `--space-24` | 96px | 페이지 하단 여백 |

사용자 화면의 주요 섹션 간격은 `--space-20`, 모바일은 `--space-14`를 사용한다. 어드민의 주요 섹션 간격은 `--space-12`를 기준으로 한다.

## 4. 컴포넌트 규칙

### 카드와 패널

- 일반 카드: `--radius-card` (`20px`), 패딩 `--space-8`; 모바일 패딩 `--space-5`
- 대표 추천·조건 패널: `--radius-feature` (`28px`)
- 어드민 패널: 패딩 `--space-6`, 모서리는 `--radius-control` 또는 `--radius-card`
- 카드 안에서 또 큰 카드를 중첩하지 않는다. 선, 배경 톤, 작은 그룹으로 위계를 만든다.

### 버튼과 입력

- 기본 높이: `--control-height` (`44px`)
- 데스크톱 어드민 조밀형 높이: `--control-height-compact` (`36px`)
- 컨트롤 모서리: `--radius-control` (`12px`)
- 주요 버튼은 깊은 녹색 또는 잉크색, 단 하나의 최우선 행동에만 라임색을 쓴다.
- 모바일에서 클릭 가능한 컨트롤은 최소 44px 높이를 확보한다.

### 배지

- 상태·취향 배지는 `--radius-pill` (`999px`)을 기본으로 한다.
- FOOD / TASTE / STYLE처럼 의미가 다른 취향 배지는 테두리, 배경, 모서리를 미세하게 달리할 수 있다.
- 같은 화면에서 모든 정보를 배지로 만들지 않는다. 짧은 상태와 선택 가능한 키워드만 배지로 표현한다.
- 선택 상태는 색상만으로 구분하지 않고 테두리 또는 굵기 변화도 함께 제공한다.

### 표와 운영 목록

- 표 셀 기본 패딩은 `--space-3`이다.
- 행 사이를 카드처럼 과하게 띄우지 않고 1px 경계선으로 연속성을 유지한다.
- 필터·검색·일괄 작업은 목록 위에서 같은 기준선에 맞춘다.
- 성공, 실패, 예외 상태는 기존 의미색을 유지하고 텍스트 라벨을 함께 표시한다.

## 5. 화면 유형별 적용

### 사용자 화면

- 히어로 → 조건/대표 카드 → 결과 섹션 순서를 명확히 한다.
- 큰 제목과 첫 조작 사이에는 `--space-12` 이하의 일관된 간격을 둔다.
- `/courses`, `/places`, `/me`는 같은 1280px 기준선에서 시작한다.
- 추천 이유와 핵심 가치 배지는 장소명보다 시각적 우선순위가 높아지지 않게 한다.

### 어드민 화면

- 사용자 화면보다 정보 밀도를 높이지만 컨테이너, 폰트, 선 색상은 공유한다.
- 페이지 시작 48px, 패널 간격 24~48px, 조밀형 컨트롤 36px를 기본으로 한다.
- 모바일에서는 컨트롤을 44px로 확대하고 다열 필터를 1~2열로 줄인다.
- 데이터의 의미와 처리 흐름은 디자인 정리 과정에서 바꾸지 않는다.

## 6. 반응형 기준

- `760px` 이하: 모바일 거터 14px, 사용자 시작 32px, 주요 섹션 56px, 카드 패딩 20px
- 넓은 표와 레일은 내용이 찌그러지기 전에 가로 스크롤 또는 단일 열로 전환한다.
- 제목은 `clamp()`를 사용하고, 모바일에서 한 줄을 억지로 유지하지 않는다.
- 바텀시트, 필터, 탭은 키보드 포커스와 선택 상태가 화면에 드러나야 한다.

## 7. 권장 / 금지

### 권장

- 토큰을 사용한 `padding: var(--space-6)`
- 공통 폭을 위한 `.admin-page-frame`
- 역할에 따라 카드 20px, 기능 패널 28px, 배지 pill 구분
- 기존 페이지의 고유한 정보 구조를 유지한 정합성 보정

### 금지

- `margin-top: 37px`처럼 근거 없는 새 값 추가
- 페이지마다 다른 최대 폭 사용
- 모든 버튼과 카드에 동일한 pill 모서리 적용
- 라임색을 여러 CTA, 경고, 장식에 동시에 사용
- 어드민 정리 중 데이터 상태나 처리 로직 변경
