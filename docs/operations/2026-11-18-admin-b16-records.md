# B16 제한 감사 내보내기·정책 문서 조회

추적: #450. 담당은 Codex B16 worker이며 통합·병합·배포는 root가 수행한다. #397은 HOLD, #360의 실제 운영·법적 사실은 OPEN으로 유지한다.

`/admin/records`는 현재 ADMIN 세션으로만 조회할 수 있다. CSV 생성은 동일 origin POST와 현재 ADMIN·최근 재인증을 요구하며, 권한을 다시 확인하는 감사 저장에 실패하면 CSV를 반환하지 않는다. 감사의 `ADMIN_AUDIT_EXPORT`는 파일 생성 사실이며 실제 다운로드·파일 저장 완료를 뜻하지 않는다.

내보내기는 UTC 시작일·종료일을 포함해 최대 31일, 요청당 1–200행이다. 기존 B06 감사/작업 영수증 목록의 정확한 종류 필터와 익명화된 참조값·시각·작업명·기록 상태만 포함한다. 이메일, 표시 이름, 자유 사유, 원문 payload, before/after 상태 원문, 상세 영수증과 DB dump는 포함하지 않는다. UTF-8 BOM과 CSV 인용을 적용하고 수식 시작 문자를 이스케이프한다. 행 상한·목록 기준 시각·다음 cursor를 표시하며 다음 페이지는 같은 기간·목록·종류·행 수에 묶인다. 새로 생긴 기록은 기존 페이지 snapshot에 합치지 않는다.

정책 영역은 현재 배포 코드에 포함된 개인정보 처리방침과 이용약관 원문의 SHA-256·초안 상태·원문 링크를 표시한다. 기존 원문 파일은 변경하지 않는다. 새 문안은 기존처럼 원문 파일을 변경하는 PR에서 검토하며 이 화면에서 저장·활성화·시행일 변경을 제공하지 않는다. #360의 실제 운영주체·문의처·보존/삭제·위탁/이전·권리/실증·복원/인계 사실을 별도로 확인하며, 미제공 값을 만들지 않는다.

새 dependency·migration·환경 변수·secret·외부 서비스·cron은 없다. 배포는 최종 통합 PR의 지정 운영 범위에서 수행한다. 문제 발생 시 이 route 사용을 중지하고 전진 수정하며, 생성된 감사 기록은 유지한다.

검증은 기간/행/필터/cursor와 CSV 수식 방어 단위시험, 현재 권한·최근 인증·출처·감사 실패·최소필드·안정 페이지의 Workers 통합시험, 데스크톱·모바일 CSV 다운로드 및 정책 조회로 한정한다. 이 결과는 전체 데이터 수출, 법률 검토 완료 또는 실제 운영 파일 저장 증거가 아니다.

2026-11-18 로컬 결과: 관련 단위 7건, Workers 통합 11건, Chromium 데스크톱·모바일 2건 통과. typecheck·build·production dependency audit 통과. 화면 증거는 [데스크톱](../evidence/admin-b16/desktop.png), [모바일](../evidence/admin-b16/mobile.png)이다. 운영 배포·운영 데이터 내보내기는 수행하지 않았다.

전체 dependency audit는 기존 개발·빌드 도구 경로의 47건(critical 1, high 16, moderate 26, low 4)을 보고했다. production audit는 0건이며 이번 변경에서 package/lockfile은 바꾸지 않았다. 기존 개발 도구 취약점은 이 기능 검증 통과와 별도로 남는다.
