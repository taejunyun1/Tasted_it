# 올더스캣 기존 매장의 공개 회수

[#474 운영 대조](https://github.com/taejunyun1/Tasted_it/issues/474#issuecomment-7188527373)

## 대상과 결정 근거

운영 Re:Taste의 `place-intake-8d16336ec3017295f4a68688` 올더스캣 한 곳이다. 주소는 광주 서구 군분로179번길 11-1이며, 원장 361번의 기존 검수 연결이다.

업체는 이 주소의 마지막 영업일을 2026-09-30로 공지했다. 10월 7일에 게시된 후기에는 실제 방문일이 9월 말로 기록돼 있다. 이후 영업 재개나 같은 주소의 새 공지는 확인되지 않았다. 이 근거는 현 매장 공개 회수에 사용한다. 허가상의 폐업일은 미확정이다. [업체 공지](https://www.instagram.com/p/DdGqfMzCSNH/embed/captioned/) · [광주시 주소 및 공식 계정 대조](https://newscms.gwangju.go.kr/gallery.es?act=view&bid=0009&cg_code=C03&list_no=4799&mid=a40200000000) · [방문 시점 본문](https://www.diningcode.com/profile.php?rid=J0BgcLnIniAy)

2026-11-26 읽기 전용 대조에서 장소는 `PUBLISHED`, `closed_at`은 비어 있고 상세는 비로그인 200이었다. 기존 원장 연결은 `FINAL_APPROVAL / COMPLETED`다. 현재 평가·방문 리뷰·개방 검수가 각 0건이고 원장 856건, 연결 83건을 확인했다. 같은 주소의 다른 상호가 확인된 실키밀키는 해당 실행의 대상에서 제외한다.

## 승인 실행

필수 CI와 이 문서를 포함한 실행 PR의 병합을 확인한 뒤 지정된 Jay/Codex 운영 담당자가 기존 Re:Taste ADMIN 세션에서 실행한다. 기준 Worker `retaste-beta`의 `1343a5e8-8bfe-496b-9950-80b41482ea90` 100%, 기존 장소·검수 상태 및 상호·주소를 바로 전에 대조한다. 운영 Worker가 다른 버전이면 해당 버전에 같은 운영 경로와 쓰기 범위를 다시 검증하여 승인 기록에 연결한다.

1. [대상 장소 운영 화면](https://retaste-beta.retaste-beta.workers.dev/admin/place-operations?place=place-intake-8d16336ec3017295f4a68688)에서 대상과 공개 상태를 확인한다. 9월 30일 기존 매장 영업 종료와 업체 원문을 회수 사유에 기록한다.
2. **공개 회수 미리보기**를 한 번 요청한다. 기존 B09는 만료된 미확정 미리보기를 최대 50건 정리한 뒤 10분 제한의 요청 한 건을 생성한다. 미리보기의 대상이 위 장소 한 곳이고 `PUBLISHED → HIDDEN`, 공개·추천 제외, 방문·평가 영향이 앞서 읽은 값과 일치해야 확정한다.
3. 같은 기존 ADMIN 세션의 유효한 재인증을 사용한다. 새 인증이 필요한 경우 비밀번호 재인증을 한 번 실행해 기존 인증 시도 제한과 10분 세션 확인 기록을 갱신한다. 이번 운영 인증 범위는 기존 ADMIN 비밀번호 재인증이다. 같은 작업을 한 번 확정한다.
4. 기존 B09는 장소의 `status`와 `updated_at`, 기존 공개 판정 epoch을 갱신한다. 새 `CATEGORY_RECALL / SOURCE_REVIEW / ACTIVE` 검수 1건, 장소 회수 감사와 관리자 확정 감사 각 1건을 기록하고 같은 작업에 확정 영수증을 남긴다. 원장 연결과 `closed_at`, 주소, 원본 사진·리뷰 및 다른 장소 작업은 보존한다. 배포·마이그레이션·외부 API·메일·요금제 변경은 없다.
5. 같은 작업 주소에서 확정 영수증·감사 각 1건과 장소 상태를 대조한다. 공개 상세 404, 동일 검색어의 비로그인 목록·지도 제외, 원장 856건과 연결 83건 및 기존 361번 연결을 확인한다. 확정 뒤에는 미리보기 본문의 사유가 지워지므로 이 실행 PR의 출처와 작업 번호를 실행 영수증에 함께 연결한다.

응답 결과가 불명확하면 같은 영수증과 운영 상태를 읽은 뒤 재시도 여부를 판단한다. 잘못된 회수를 확인하면 원래 작업 번호와 재인증을 대조해 기존 단일 회수 복원 미리보기와 확정을 각각 한 번 허용한다. 복원 미리보기에도 같은 만료 미확정 미리보기 정리 최대 50건이 적용된다. 새로운 영업 재개 근거는 B09 검수에서 판단한다. B17과 #397은 보류한다.
