# B14 점검·경보·검증 근거

추적 #451. `admin/reliability`는 기존 감사의 RSI 고정 6경로 결과 최근 20건, 마지막 정기 실행, 열린 경보 우선 50건과 버전이 고정된 근거를 조회한다. 12시간을 넘긴 관측은 오래됨으로 표시한다. 누락·생략·불완전 결과는 정상으로 세지 않는다. 현재 HTTP 조회는 외부 점검이나 클라우드 API를 실행하지 않는다.

경보의 기존 직접 해결 경로는 405로 닫는다. 단일 경보의 `OPEN` 상태·발생횟수·마지막 시각·종류·심각도·출처·최초시각을 B02 미리보기에 묶고, 확정 시 현재 ADMIN·세션·최근 인증과 원자 CAS를 검사한다. 새 발생이 먼저 기록되거나 감사 저장이 실패하면 처리 전체가 롤백된다. 처리는 사람의 검토 이력이며 실제 장애 복구 판정이 아니다. 경보 원문·출처 식별자·개인정보는 화면 응답에 포함하지 않는다.

0056은 기존 admin_operations/commits/checks의 rowid와 모든 필드를 보존하고 OPERATIONAL_ALERT_RESOLVE kind만 추가한다. 선행 0052, 0054, 0055의 kind를 포함한다. 새 테이블·provider·cron·binding·dependency는 없다. 기존 Worker는 새 kind를 지원하지 않으므로 운영 순서는 선행 작업과 합쳐 root가 확정한다. 적용 전 백업·기존 값 digest를 확보하고, 적용 뒤 기존 값·영수증·FK를 대조한다. 실패 시 점검 fence를 유지하고 전진 수정하며 운영 DB 덮어쓰기·실제 복원은 하지 않는다.

근거 manifest는 검토된 저장소 JSON 두 건의 commit·경로·SHA-256만 연결한다. 과거 B09 배포 점검과 로컬 합성 D1 왕복 복원 연습이며, 현재 운영 배포·백업·복구 성공을 증명하지 않는다. 임의 URL 입력이나 사용자 제공 근거 URL의 자동 방문은 없다. 메일 도메인·실제 발신 판정은 B11의 별도 범위다.

로컬 필수 검증: 권한·최근 인증·새 발생 CAS·감사 실패 롤백·중복 영수증·원문 비노출·RSI 불완전/오래됨, 0056 이력 보존, manifest 파일 digest, 데스크톱/모바일 조회와 미리보기. 운영 검증은 병합된 root의 한정 rollout에서 수행한다. 이번 운영 검증에서 실제 경보 변경·해결은 0건이며, 기존 ADMIN의 읽기/부정 경로와 명시된 기존 고정 RSI 확인만 수행한다. #397은 HOLD다.
