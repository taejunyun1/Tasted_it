- 운영 적용 승인 원본: 이 계약을 포함하는 병합 PR. 병합 전 실제 설정 변경 0

## 범위

설정 화면은 13개 고정 allowlist 값의 저장소 기대값·현재 요청 해석을 조회한다. 임의 환경 변수, 비밀값, DNS, 배포 API를 나열하거나 수정하지 않는다. 유일한 앱 내 변경 대상은 `REVIEW_AUTO_PIPELINE_ENABLED`에 대응하는 **동기화 후 자동 검수의 다음 진입 허용**이다. 다른 설정은 조회만 제공한다.

`scheduled-sync.server.ts`의 해당 진입점에서 환경 기준값이 `true`이고 D1의 중단 기록을 정상적으로 읽었으며 `stopped=0`일 때만 자동 검수를 시작한다. 환경값이 꺼졌거나 잘못됐거나 중단 행이 없거나 조회가 실패하면 실행하지 않는다. 기존 `CST_MAINTENANCE`의 데이터베이스 접근 이전 HTTP/cron fence는 그대로 둔다.

## 변경·복원

`admin_feature_stops`는 허용 키 한 개와 중단 여부·version·변경 시각·변경 주체만 저장한다. 초기 migration은 중단 없음/version0이며 환경 기준값을 켜지 않는다. 작업별 사유는 기존 작업/감사 영수증에 남긴다. 변경 주체는 기존 계정을 참조하며 추가 프로필 자료를 수집하지 않는다. 새 보존 기간·외부 공급자·cron은 추가하지 않는다.

미리보기는 현재 중단 여부/version과 환경 기준값을 고정한다. 확정은 현재 ADMIN 권한·최근 재인증을 확인하고, 같은 D1 batch 안에서 version과 이전 값이 일치할 때만 한 번 변경·감사 기록을 반영한다. 같은 영수증 재조회는 재변경하지 않으며 현재 상태도 다시 읽는다. 응답 유실은 새 변경을 만들기 전에 같은 영수증으로 확인한다.

중단 해제는 환경 기준값으로 돌아가는 동작이다. 환경값이 `false`/미설정이면 활성화할 수 없다. 미리보기 뒤 환경값이나 version이 달라지면 확정을 거절한다.

## 실행 중 작업과 한계

중단 전에 진입 검사를 통과한 자동 검수는 계속될 수 있다. 이미 시작한 파이프라인을 취소하거나 이전 결과를 되돌리는 기능이 아니다. 공공 인허가 수집·별도 NAVER 검증·수동 검수 역시 이 키의 중단 대상이 아니다. 이 범위를 관리자 화면에 표시한다.

저장소 기본값과 현재 Worker 환경의 공급 경로·배포 SHA는 서로 다른 정보다. 실제 배포 버전 또는 설정 주입 출처가 확인되지 않으면 미확인으로 표시한다. 플래그 허용을 외부 API 성공이나 완료 증거로 표시하지 않는다.

## 검증과 rollback

로컬 검증은 default 일치·invalid masking·미사용 flag, 일반 회원/익명 차단, D1 오류 fail-closed, 최근 인증·version 경합·재조회, 환경 기준값 false 활성화 거절, desktop/mobile 중단·해제 흐름만 수행한다. 운영 검증은 승인된 배포 뒤 조회와 부정 경로를 우선하며 실제 중단/해제는 병합 PR에 특정한 경우만 실행한다.

0054는 기존 작업·영수증·검사 rowid와 감사 guard를 보존한다. 이전 Worker로 rollback할 경우 이전 코드가 D1 중단 기록을 읽지 않는다는 점에 유의한다. 중단을 유지해야 하는 rollback이면 먼저 기존 환경의 `REVIEW_AUTO_PIPELINE_ENABLED=false`로 배포하는 승인 절차를 따른다. DB 행을 지우거나 과거 migration을 고치지 않는다. 기능 제거는 같은 키의 소비 경로와 보존된 감사 이력을 별도로 검토한다.
