# TEMP100 비공개 관리자 검수·프리뷰 정책

- 상태: 구현 PR 검토 대상. 사용자 2026-11-14 요청의 **실제 웹 자료 기반 초기 TEMP 100곳**, 후속 **관리자 검수·프리뷰 우선** 범위다.
- 추적: [#400](https://github.com/taejunyun1/Tasted_it/issues/400).
- 소유: Jay/Codex. 운영 D1/R2 반입·웹 관리자 연결·발행·배포는 이 PR의 실행 범위가 아니다.
- 상위 기준: [CST 구현 정책](2026-11-13-cst-implementation-policy.md), [CST 실행계획](../plans/2026-11-13-cst-service-ssot.md). 상위 문서의 일정·관리자 권한·공개 승인·평가 산식을 바꾸지 않는다.

## 1. 기존 축적 금지와 이번 허용 범위

기존 CST 정책의 외부 원문·사진·평점·외부 식별자 축적 금지 중, 사용자가 요청한 초기 TEMP 자료 준비에 필요한 다음 범위만 비공개로 예외 처리한다.

- 실제 장소의 공개 사실과 짧은 독자 요약, 공식 소개·선정의 출처·확인일.
- 외부 사진의 원본 페이지/파일 링크와 이용조건·저작자·출처표시·개별 저작물 근거.
- 재사용 근거가 확인된 사진의 한정된 로컬 사본과 SHA-256. 소스의 일반 저작권 문구만으로 개별 사진의 권리를 추정하지 않는다.

긴 후기 원문, 개인정보·연락처, 로그인 자료, 유료 API, 약관 우회, API 키 탐색은 포함하지 않는다. 실제 방문일·촬영일·리뷰어 계정·관리자 승인·내부 투표·Golden·추천점수는 만들지 않는다. 공식 맛집 선정은 `OFFICIAL_CURATION`이며 고객 평점으로 이름을 바꾸지 않는다. 외부 숫자 평가는 저장하지 않고 원본 참조로 남긴다.

`TEMP100`은 실증·영업·권리 검수 완료 수량이 아니다. 100개 목록, 실제 사진 링크 수, 재사용 근거 수, 로컬 사진 프리뷰 수, 남은 권리 확인 수를 각각 보고한다. 링크 100개를 사진 확보 100개라고 하지 않는다.

## 2. 장소와 검수 상태

광주·전남의 실제 음식점을 대상으로 하며 기존 `local-dining-v1`의 체인(로컬 체인 포함)·비음식·유흥·배달전문 제외 및 불명확한 업종 보류를 유지한다. 공식 목록에 있다는 사실은 현재 영업·독립 점포·실제 현장 확인의 증명이 아니다.

모든 행의 기본값은 `PRIVATE / QUARANTINED / PENDING_REVIEW`다. 초기 웹 점검의 `NO_CHAIN_SIGNAL`은 체인이 아니라는 최종 판정이 아니다. 중복은 정규화한 상호+주소 및 출처로 점검하되, 실제 기존 D1 장소와의 중복 확인은 아직 수행하지 않은 별도 gate다. 폐업·업종·지점 불일치가 확인된 행은 후보 수를 채우기 위해 유지하지 않고 대체하거나 제외한다.

## 3. 사진 권리와 로컬 프리뷰

권리 판단은 다음 2026-11-14 공개 primary 자료를 기준으로 한다.

| 근거 | 적용 |
| --- | --- |
| [공공누리 유형별 조건](https://www.kogl.or.kr/info/license.do), [이용안내](https://www.kogl.or.kr/info/userGuide.do) | 개별 저작물의 유형과 출처표시 조건을 확인한다. 0/1유형, CC0, CC BY/CC BY-SA의 명시된 허용 범위 안에서만 로컬 사본을 준비한다. AI 전용 허락을 서비스 사진 표시 허락으로 보지 않는다. |
| [광주시 저작권 정책](https://www.gwangju.go.kr/contentsView.do?pageId=www818) | 개별 공공누리 표시 없는 자료는 별도 협의 대상이다. 공개 관광 페이지라는 이유만으로 사진을 복사하지 않는다. |
| [포토코리아 이용·저작권 안내](https://phoko.visitkorea.or.kr/main/index.kto) | 회원가입·사용 용도 및 개별 유형 조건이 있으므로 무로그인 다운로드 가능한 일반 웹 사진으로 취급하지 않는다. 이번 작업에서 가입·동의하지 않는다. |
| [여수시 관광사진 다운로드](https://www.yeosu.go.kr/tour/operation_guide/photo_download) | 해당 갤러리가 명시한 수정·이용 허용 및 공공누리 1유형을 확인하고, 실제 사진 상세·저작자·장소 일치를 별도로 연결한다. 다른 사이트 이미지까지 허락이 확장되지 않는다. |

권리 미확인은 `LINK_ONLY_UNCONFIRMED`로 남기고 자동 hotlink·다운로드·프록시를 하지 않는다. 권리 근거가 있는 사진은 `PERMITTED`와 license type, 저작물 상세 근거, 저작자, attribution을 기록한다. 로컬 원본이 있는 경우에도 최종 관리자 권리·개인정보·장소 검수는 `PENDING`이다.

프리뷰는 로컬 0600 HTML에서만 열며 외부 스크립트·자동 외부 이미지 요청을 차단한다. 허용 근거가 있는 로컬 이미지의 경로·크기·magic bytes·SHA-256을 대조한 경우에만 해당 이미지를 표시한다. 미확인 사진은 차단 사유와 사용자가 선택하는 원본 링크를 보여 준다. 저작자를 누락하거나 일반 요리 사진을 특정 점포 사진으로 바꾸지 않는다. EXIF/GPS 제거 여부, 인물·차량번호 노출 검토가 완료되지 않은 원본은 공개 업로드하지 않는다.

## 4. 파일·도구 경계와 반복 실행

실제 데이터와 출처 manifest는 저장소에서 제외된 `.superpowers/operations/temp100-seed-YYYYMMDD-*` 아래에만 둔다. 디렉터리 0700, 파일 0600을 검사하며 외부 경로·심볼릭 링크·예상하지 않은 입력 파일·크기 초과·민감 query parameter를 거절한다. stdout과 공개 증거에는 집계·해시만 출력한다.

`scripts/temp100-candidates.mjs --prepare --private-dir <전용 디렉터리>`는 고정된 두 shard를 검증한 뒤 아래 자료를 만든다. 네트워크 호출·DB 명령·업로드·공개 action은 없다.

- `candidates.json`: 100개 비공개 TEMP 행 및 원본 출처·권리 상태.
- `preview.html`: 관리자 로컬 검수 프리뷰.
- `import-plan.json`: 안정적인 장소 key와 revision hash, 남은 검수 항목. 실행 가능한 SQL/공개 상태를 만들지 않는다.
- `aggregate.json`: 수량·차단·사진 근거·프리뷰 수 및 dataset hash만 포함.

같은 입력의 재실행은 같은 key/hash를 만든다. 기존 결과가 다른 경우 덮어쓰지 않고 `TEMP100_ARTIFACT_CONFLICT`로 중단한다. 수정본은 원본을 보존한 새 전용 디렉터리 또는 검토된 새 revision으로 준비한다. 권리 요청·오인 연결·개인정보 문제가 생기면 해당 원본을 프리뷰에서 즉시 보류하고 로컬 사본 제거와 관련 참조 정합성을 확인한다. 최초 수집 후 7일 이내 및 12/10 인계 전에 권리·보관 필요성을 재검토하며, 자동 삭제 작업이 구현됐다고 주장하지 않는다.

## 5. 기존 관리자 경로와 다음 연결점

`/admin/import`는 관리자·동일 origin 검사 후 CSV를 읽지만 `DRAFT/PUBLISHED/HIDDEN`을 수용하고, TEMP 출처/권리 manifest를 보존하지 않는다. 이를 그대로 이용하면 자료의 성격을 잃거나 의도치 않게 공개할 수 있어 이 데이터의 직접 import 경로로 사용하지 않는다.

`upsertBusinessLicense`는 실제 인허가 source/관리번호를 전제로 한다. 웹 TEMP에 가짜 인허가 식별자를 붙이지 않는다. 후보 승인 경로는 실제 장소를 `PUBLISHED`로 생성하므로 자동 연결하지 않는다.

다음 최소 연결안은 기존 관리자 인증·동일 origin 경계를 사용하는 **TEMP 전용 검증·읽기 프리뷰 adapter**다. 별도 구현 PR에서 출처와 권리 manifest 유지, 서버 강제 비공개, 기존 장소와의 중복 연결, 행별 반려·수정, 감사, 정확한 삭제를 검증한다. 운영 영속화가 필요하면 저장 위치·보존·대상/한도·비용·rollback을 먼저 명시한다. 이 준비 PR은 해당 adapter 또는 운영 반입을 구현/승인하지 않는다.
