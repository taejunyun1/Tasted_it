# B08 리뷰어 일괄 변경 계약

- 상태: ACCEPTED_IMPLEMENTATION — #435의 리뷰어 범위. 학생 업무는 별도 PR이다.
- 기준: `origin/main@d9d6981`과 공통 people-operation 계약. 운영 적용은 이 문서를 포함한 PR 및 [B08 실행 계획](../operations/2026-11-14-admin-b08-rollout.md)을 따른다.

## 기존 기준과 근거

일반 승인 기준은 **신청 당시 저장된 승인 제안 수 10곳 이상**을 유지한다. 현재 승인 제안 수는 별도로 조회하고 미리보기에 함께 표시하며, 미리보기 뒤 바뀌면 해당 묶음을 재검토한다. 현재 수치가 10곳을 넘었다는 이유로 신청 당시 기준 미달을 일반 승인으로 바꾸지 않는다. 예외 승인·반려·상태 변경에는 기존과 같이 사유가 필요하며 최대300자로 제한한다.

기존 도메인 helper와 호출 계약은 보존한다. 관리자 HTTP 경로는 새 미리보기·확정 방식만 수용하므로 오래된 페이지의 직접 변경 POST는 거절한다. 신청 의견서는 심사에 필요한 관리자 화면에서만 표시하며, 이메일 원문·세션 식별자·신청 의견서·사유를 작업 영수증으로 복제하지 않는다.

## 선택·미리보기·동시 변경

한 작업은 같은 변경 종류의 최대25개 대상이다. 중복 ID와 초과 선택을 거절한다. 자동 휴면은 기존90일 기준을 만족하는 후보 중 최대25명을 먼저 선택하고 미리보기에서 고정한다. 확정 시 다시 전체 조건 검색으로 대상을 확대하지 않는다.

미리보기는 READY 또는 SKIPPED와 고정 사유 코드를 기록한다. 종료된 신청, 기존 프로필, 신청 당시 기준 미달, 이미 같은 상태, 휴면 조건 미달, 관리자 보호, 탈퇴·접근 제한을 구분한다. 동일 신청자의 승인 가능한 신청이 여러 개면 ID 순서의 첫 신청만 대상으로 잡고 나머지는 DUPLICATE_APPLICANT로 제외한다. 변경 대상이 없으면 쓰기 영수증 없이 제외 결과만 보여 준다.

READY 대상에는 신청/프로필의 단조 증가 version, 사용자 역할·갱신 시각, 회원 접근 제한 version, 신청의 현재 승인 제안 수, 휴면의 마지막 활동과 생성할 프로필 주소를 묶는다. 공통 migration의 version 트리거는 같은 timestamp의 기존 helper 쓰기와 새 활동도 포착한다. `RETURNING`이 AFTER-trigger 전 값을 반환하는 것에 의존하지 않는다.

확정은 하나의 `REVIEWER_ADMIN_CHANGE` 작업이며 최근 관리자 재인증을 요구한다. READY 전부의 CAS·도메인 변경·감사·중앙 영수증을 같은 D1 transaction에 넣는다. 한 대상이라도 바뀌면 변경 전부를 중단하고 READY는 NOT_APPLIED/CONFLICT로 표시한다. 미리보기에서 제외한 대상은 계속 SKIPPED이며 새로 변경하지 않는다.

## 결과·재조회·공개 경계

성공 결과는 `change`, `requestedCount`, `appliedCount`, `skippedCount`, `results[{targetRef,targetId,targetType,outcome,code}]`를 담는다. 이름·신청 문안·사유는 결과에 저장하지 않는다. 관리자 화면은 내부 targetId로 현재 이름을 다시 조회해 각 결과의 대상을 식별하며, B06에는 건수만 표시한다. 응답이 유실되면 같은 operationId의 정확한 감사·확정 영수증을 재조회하고 재실행은 저장된 결과만 반환한다. 결과를 입증하지 못하면 UNKNOWN으로 표시하며 성공이나 미반영0건으로 단정하지 않는다.

활동 재개·휴면·정지는 기존 승인 콘텐츠의 노출과 리뷰어 점수 참여 자격에 영향을 준다. 이 작업은 방문·사진의 검수 상태를 변경하지 않으며, WITHDRAWN/REJECTED 상태를 승인이나 공개로 되돌리지 않는다. 새 콘텐츠 자동 승인, 외부 호출, 보존 정책 변경은 포함하지 않는다.

관리자 화면과 오류·리다이렉트는 private/no-store를 유지한다. 목록은 종류별50명 상한이며 초과 시 상태·검색 조건을 좁히도록 표시한다. 폼은 URL-encoded 16KiB 이내이고 허용하지 않은 필드·중복 단일 필드·직접 변경 intent를 거절한다.
