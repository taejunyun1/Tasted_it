# 장소 사진 관리자 검증

2026-11-26 로컬 합성 검증. 운영 D1, R2와 실제 사진을 사용하지 않았다.

- 데스크톱 Chromium과 Pixel 7 Chromium에서 일반 회원의 미리보기와 관리 화면 접근 거절, 관리자 사진 ID 조회, 비공개 JPEG 표시, 재인증 요구, 공개 승인과 회수를 확인했다. 회수 후 미리보기 요청의 응답은 404였다. 재인증 완료 상태는 합성 세션으로 구성했다. [데스크톱](desktop-review.png) · [모바일](mobile-review.png) · [브라우저 테스트](../../../tests/e2e/admin-poi-media.spec.ts)
- D1 통합 33건에서 JPEG 해시·형식 불일치, 폐업, 상호·주소 변경, TEMP, 권한·세션·재인증 변경, 같은 사진의 동시 승인과 회수, 감사 실패 시 롤백, 공개·비공개 응답을 검증했다. [관리자 상태](../../../tests/integration/poi-media-admin.test.ts) · [상호와 주소](../../../tests/integration/poi-media-identity.test.ts) · [공개 경로](../../../tests/integration/poi-media-route.test.ts) · [감사 조회](../../../tests/integration/admin-activity.test.ts)
- 운영 장부와 동일한 56개 마이그레이션을 적용한 메모리 D1에 0063·0064를 추가했다. 장부는 58개였으며 기존 스키마 객체 420개와 합성 장소·관리자 영수증·반입 원장을 보존했다. 새 스키마 객체는 6개, 보류한 B17 항목의 추가 적용과 외래 키 위반은 각각 0건이었다. 같은 두 마이그레이션을 재실행했을 때 신규 적용 0건을 확인했다.
- 동일한 기준 D1의 별도 합성 사례에서 0054 → 0055는 기존 영수증을 보존하고 `PHOTO_CLEANUP_RETRY`와 `PRIVACY_REQUEST_UPDATE` 영수증을 지원했다. 0055 → 0054는 새 유형의 사용을 막았고, 이미 해당 유형의 영수증이 있으면 `CHECK` 제약으로 전체 0054 적용이 롤백됐다.

공개 기능 플래그 활성화와 실제 운영 사진 반입은 대기다. 56개 장부의 장소 사진 호환성 검증은 최신 Worker 전체의 운영 호환성을 확인하는 별도 검증과 함께 사용한다.
