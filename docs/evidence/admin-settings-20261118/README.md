# B12 설정 조회·자동 검수 중단 검증

2026-11-18 · #449 · 합성 계정과 로컬 D1으로 검증했다. 운영 설정 변경·외부 공급자 호출은 0건이다.

- 설정 13개만 읽고 환경 전체를 반환하지 않는다. 잘못 주입된 원문 값·자격정보를 응답에 포함하지 않는다.
- 저장소 기본값과 현재 요청의 해석, 미설정·미사용 flag·주입 출처/배포 버전 미확인을 구분한다. `PLACE_CATEGORY_V5_ENABLED`는 현재 소비 경로가 없어 활성 기능으로 표시하지 않는다.
- 유일한 변경 항목은 `REVIEW_AUTO_PIPELINE_ENABLED`의 다음 자동 검수 진입이다. 최근 재인증·version CAS·원자 감사·같은 영수증 재조회, 환경 false 강제 활성화 거절을 확인했다.
- D1 조회 실패·행 누락에서 실행하지 않는다. 실제 `runScheduledCandidateSync` 진입을 호출하여 중단 전 자동 검수 호출 1회, 중단 뒤 추가 호출 0회, 공공 수집은 두 번 모두 진행됨을 확인했다. 외부 응답과 자동 검수 본문은 시험 경계에서 대체했다.
- 0054의 기존 작업/영수증/검사 rowid·FK·불변 guard 보존과 고정키 제한을 검증했다.
- Chromium desktop/Pixel 7에서 일반 회원 403, 관리자 no-store, 중단→해제의 미리보기·현재 상태, 가로 넘침 없음을 확인했다. 테스트용 환경 기준값은 true이며 운영 값의 증거가 아니다.
- 초기 로컬 시험에서 Content-Type 없는 POST의 FormData 예외를 발견하여 400으로 거절하도록 고쳤다. 변경된 data 반환형에 대한 검사기 접근도 교정했다.
