## 첫 실패 보존

사진/별도 평가/저장 참여자까지 footprint를 확장한 첫 실행은 새 7건이 모두 `D1_ERROR: too many terms in compound SELECT`로 실패했고 기존 병합 6건은 통과했다. 반복된 UNION 기반 회원 범위를 단일 MATERIALIZED people_scope와 OR 범위 조회로 바꿔 동일한 의미를 유지했으며, 이후 새 7건이 통과했다. 기존 공개 재분류/제한 참여자 회귀를 추가한 8건도 통과했다. 최종 공개 우회 차단 1건을 추가한 9건이 다시 통과했다. timeout/retry/test skip을 바꾸지 않았다.

## 완료 경계

공통 계약·운영 계획·registry는 통합 담당 커밋이다. 전체 필수 CI와 main 병합, 운영 배포, 읽기/거절 중심 live 검증은 이 로컬 검증과 별개다. 회수 복원은 일반적인 undo가 아니며 현재 근거가 달라지면 차단한다. 기존 평가 원장과 사진 파일은 삭제·이전하지 않는다.
