2026-11-13 #370, CST U04/S03→S07/T05의 로컬 합성 검증이다. 운영 배포·메일 발송·공개정보 변경은 실행하지 않았다.

- 상세의 정정 링크가 정확한 장소 ID를 전달하고 form과 새로고침에서 같은 장소를 선택한다.

- 최초 집중 시험 7건 실패로 누락을 재현한 후 관련 integration 2파일 10건, desktop/mobile Playwright 2건을 통과했다. 타입 검사·빌드도 통과했다.
- [desktop.png](./desktop.png), [mobile.png](./mobile.png)는 실제 로컬 화면이다. 선택 장소와 관리자 검토 전 공개정보가 바뀌지 않는 안내를 시각 확인했다. 샘플 fixture의 상호·주소이며 실제 이용자 입력은 없다.
