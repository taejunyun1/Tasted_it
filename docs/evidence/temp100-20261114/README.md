# TEMP100 비공개 준비 증거

- 추적: [#400](https://github.com/taejunyun1/Tasted_it/issues/400), [격리 정책](../../decisions/2026-11-14-temp100-seed-quarantine.md).
- 상태: **PARTIAL_PHOTO_RIGHTS_PENDING**. 100개 목록 준비와 실제 사진 100개 확보 완료를 구분한다.
- 확인일: 2026-11-14 KST. 공개 저장소에는 실제 상호·주소·원문·사진·실제 데이터 파일을 포함하지 않는다.

## 확인된 범위

| 항목 | 확인 결과 |
| --- | ---: |
| 고유 실제 장소 후보 | 100 |
| 공식 장소 출처 / 외부 소개·선정 참조 | 100 / 100 |
| 실제 웹 사진 URL 참조 | 100 |
| 개별 재사용 근거가 연결된 로컬 사진 | 3 |
| 비공개 프리뷰의 실제 사진 로드 | 3 / 3 |
| 사진 권리 근거 미확인 | 97 |
| 공개 / 내부 점수 / 외부 숫자 평점 저장 | 0 / 0 / 0 |
| 영업·체인·최종 관리자 검수 확정 | 0 |

외부 평가 필드는 공식 소개·선정 자료의 참조다. 실제 고객 평점, 내부 추천률 또는 현장 방문 평가로 변환하지 않았다. 웹 자료에서 눈에 띄는 체인·지점·비음식·중복 후보를 제외했지만, `NO_CHAIN_SIGNAL`은 독립점·현재 영업 확정이 아니다.

## 실제 사진 pilot

서로 다른 3개 음식점의 여수시 공식 상세와 해당 사진 갤러리 항목을 연결했다. 갤러리 범위의 공공누리 1유형·기관 제공자·출처표시를 확인하고 촬영자 미표시와 과거 등록일을 구분했다. 2장은 RGB 픽셀을 유지한 metadata 제거본이고 1장은 실제 사진의 축소본이다. 생성 이미지나 다른 식당 사진을 대신 넣지 않았다.

차량번호 노출 및 장소 별칭 불명 사진은 표시 대상에서 제외했다. 원본과 변경 근거는 비공개로 보존하며, 프리뷰는 표시 가능한 사본의 검증된 바이트를 내장한다. 이후 원본 파일 교체로 이미 생성된 프리뷰가 바뀌지 않는다.

로컬 브라우저에서 100개 카드, 이미지 3개 로드, 내장 data URL 3개, 외부 요청 0, 페이지 오류 0을 확인했다. 실제 상호·사진이 있는 화면 증거는 비공개 폴더에만 저장했다. 이 결과는 웹 관리자 화면 연결·운영 반입·발행·현재 영업·최종 권리 검수 완료의 증거가 아니다.

## 재현과 보존

기존 권한 있는 비공개 폴더를 지정한다. 명령은 로컬 파일 검증·프리뷰 작성만 하며 네트워크·DB·R2 작업이 없다. 기존 결과가 다르면 덮어쓰지 않는다.

```sh
node scripts/temp100-candidates.mjs --prepare --private-dir "$TEMP100_DIR"
pnpm exec vitest run tests/unit/temp100-candidates.test.ts
```

집중 시험 11개가 통과했다. 최초 구현 부재의 compile RED, 추가 파일 경계 runtime RED, 검증 후 원본 교체로 이전 프리뷰가 변하는 runtime RED를 각각 보존했다. 사진 내장은 바이트 스냅샷으로 고정했다. 이후 2MiB보다 큰 정상 프리뷰의 동일 재실행이 입력 metadata 상한 때문에 거절되는 결함도 재현하고 파일별 산출물 상한으로 수정했다. 실제 4,050,853바이트 프리뷰를 재실행한 뒤 네 산출물의 SHA가 모두 그대로임을 확인했다. Node 구문·diff 검사와 production 의존성 audit도 통과했으며 새 의존성·운영 설정 변경은 없다. 전체 suite를 로컬에서 반복하지 않았다.

집계의 dataset SHA-256은 비공개 `candidates.json` 전체 내용의 해시다. 실제 dataset·원본/변환 사진·출처/권리 sidecar·브라우저 증거는 0700/0600 private operations 폴더에 있다. 이전 후보와 제외 사진의 근거도 그 안에서 분리 보존했다.

## 남은 작업

- 나머지 97개 사진의 명시 재사용 근거와 비식별 프리뷰 확보. 원문 링크만으로 완료 처리하지 않는다.
- 현재 영업, 체인·독립 점포 여부, 사진-장소 일치, 개인정보, 실제 관리자의 행별 검수.
- 기존 장소 중복 연결 및 웹 ADMIN 전용 TEMP adapter. 현재 CSV/인허가 후보 경로에 그대로 반입하지 않는다.
- 운영 반입·공개는 대상·한도·보존·비용·검증·rollback을 명시한 별도 PR 범위다.
