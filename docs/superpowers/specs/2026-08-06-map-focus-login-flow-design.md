# 지도 선택 포커스와 로그인 흐름 확정안

## 목적

회원 지도에서 목록과 마커가 같은 선택 동작을 사용하고, 로그인 여부와 로그인 후 이동 결과를 사용자가 즉시 이해하게 한다.

## 지도 선택

- 목록 또는 마커를 선택하면 `selected` URL 상태를 먼저 갱신한다.
- 선택된 장소 좌표로 지도를 이동하고 줌 16보다 멀리 보던 경우 줌 16으로 확대한다.
- 기본 모션은 네이버 지도 `morph`와 `easeOutCubic`, 520ms를 사용한다.
- 선택 마커에는 같은 시간의 단일 링 펄스를 적용한다.
- `prefers-reduced-motion` 사용자는 애니메이션 없이 즉시 중심과 줌을 변경한다.
- 선택 이동 중 발생한 지도 idle 이벤트는 검색 경계를 덮어쓰지 않는다.

## 로그인과 세션 표시

- 로그인 성공 목적지는 `returnTo`와 무관하게 메인 지도 `/`로 고정한다.
- 로그인된 사용자가 `/login`에 접근하면 `/`로 이동한다.
- 로그인 상태는 초록 상태점과 `로그인됨 · 표시 이름`으로 표시한다.
- 로그인 실패는 기존처럼 로그인 화면에 오류를 표시한다.
- 로그아웃은 세션을 제거하고 `/`로 이동하며 헤더를 로그인 링크로 되돌린다.

## 검증

- 내부·외부 `returnTo`가 모두 `/`를 반환하는 단위 테스트
- 목록 선택이 지도 포커스 상태를 만드는 E2E 테스트
- 로그인 Form action 고정, 로그인 사용자 우회, 상태 표시, 로그아웃 복귀 E2E 테스트
- 타입 검사와 프로덕션 빌드
