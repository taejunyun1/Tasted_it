# 회원 카테고리 탐색과 내 취향 기능 설계

## 목표

공공데이터 후보의 대표 카테고리를 안전하게 자동 선택하고, 공개된 장소를 회원이 카테고리별로 탐색·평가·저장한 뒤 `내 취향`에서 다시 확인할 수 있게 한다.

## 어드민 후보 검수

- 후보 선택 시 상호명, 원천 세부업태, 주소로 `classifyCandidate`를 실행한다.
- 추천된 활성 소분류를 대표 카테고리 선택값으로 자동 지정한다.
- 선택창 위에 신뢰도 `높음/보통/낮음/충돌`과 판단 근거를 표시한다.
- 후보를 바꾸면 대표 카테고리, 신뢰도, 자동 추출 동네를 함께 갱신한다.
- 낮음과 충돌도 관리자가 수정할 수 있도록 선택값은 제공하되 경고 색으로 구분한다.
- 보조 카테고리 입력과 신규 승인 저장을 제거한다. 기존 `place_categories` 보조 행은 데이터 호환성을 위해 삭제하지 않는다.

## 회원용 메인 카테고리

- DB의 활성 대분류와 활성 소분류를 사용하며 코드에 카테고리를 고정하지 않는다.
- `PUBLISHED` 장소의 대표 카테고리로 사용된 소분류만 노출한다.
- 대분류별로 소분류를 묶고 각 소분류에 공개 장소 수를 표시한다.
- 소분류를 누르면 기존 `/maps/:categorySlug` 지도·목록으로 이동한다.
- 공개 카테고리가 하나도 없으면 데이터 동기화 오류처럼 보이지 않는 안내 빈 상태를 표시한다.

## 로그인과 전역 내비게이션

- 현재 이메일·표시 이름 베타 로그인을 유지한다.
- 루트 loader에서 선택적 세션 사용자를 읽어 모든 화면의 헤더 상태를 일관되게 만든다.
- 비로그인 헤더에는 `로그인`, 로그인 헤더에는 표시 이름, `내 취향`, `로그아웃`을 표시한다.
- ADMIN 사용자에게만 어드민 검수 링크를 추가한다.
- 로그아웃은 POST 요청으로 현재 세션을 삭제하고 쿠키를 즉시 만료한 뒤 메인으로 이동한다.
- 비로그인 사용자가 장소 평가·저장을 누르면 기존처럼 로그인 후 원래 장소로 복귀한다.

## 내 취향 페이지

- 경로는 `/me`이며 로그인 사용자만 접근한다.
- 상단에 표시 이름과 이메일을 보여준다.
- `저장한 장소`에는 현재 공개 중인 저장 장소를 최근 저장순으로 표시하고 즉시 저장 해제할 수 있다.
- `내가 평가한 장소`에는 현재 공개 중인 장소, 추천/비추천 상태, 마지막 변경 시각을 표시한다.
- 장소 카드는 기존 공개 장소 카드 표현을 재사용하고 상세 페이지로 연결한다.
- 저장 또는 평가 기록이 없으면 각각 다음 행동을 안내하는 빈 상태를 표시한다.

## 데이터와 보안

- 새 테이블이나 마이그레이션은 추가하지 않는다. `sessions`, `saved_places`, `current_votes`, `places`, `categories`를 사용한다.
- 회원 조회는 항상 현재 세션 사용자 ID로 제한한다.
- 숨김·초안 장소는 메인 카테고리 수, 저장 목록, 평가 목록에서 제외한다.
- 상태 변경은 React Router action의 POST 요청으로만 처리한다.

## 오류 처리

- 만료되거나 없는 세션은 로그인 화면으로 보낸다.
- 이미 삭제된 저장 항목의 해제 요청은 성공으로 간주한다.
- 존재하지 않거나 비공개인 장소는 회원 목록에서 노출하지 않는다.
- 자동 추천 카테고리가 비활성 또는 존재하지 않으면 대표 카테고리는 미선택 상태로 두고 직접 선택을 요구한다.

## 테스트와 완료 기준

- 자동 대표 카테고리 선택과 신뢰도 표시용 데이터 변환을 단위 테스트한다.
- 공개 장소가 있는 활성 카테고리만 집계되는지 통합 테스트한다.
- 회원별 저장·평가 목록 격리와 비공개 장소 제외를 통합 테스트한다.
- 로그아웃 세션 삭제와 쿠키 만료를 테스트한다.
- 데스크톱과 모바일에서 메인 카테고리, 로그인 헤더, 내 취향 빈 상태 및 목록을 브라우저로 확인한다.
- 전체 단위·통합 테스트, 타입 검사, 프로덕션 빌드가 통과해야 한다.
