# 관리자 자동 분류 검수 UX 설계

## 목표

공공데이터를 가져온 뒤 관리자가 별도 상단 버튼을 눌러야 하는 단계를 없앤다. 동기화가 끝나면 신규 검수 후보 10곳을 별도 요청으로 자동 분류하고, 관리자는 수동 확인이 필요한 후보만 빠르게 넘겨보며 다시 분류하거나 승인한다.

## 확정 사용자 흐름

1. 관리자가 공공데이터 동기화를 실행한다.
2. 동기화 요청은 데이터 적재까지만 수행한다.
3. 성공하면 `/admin/candidates?autoClassify=1`로 이동한다.
4. 검수 목록이 열린 뒤 별도 요청으로 신규 대기 후보 최대 10곳을 자동 분류한다.
5. 자동 분류 결과가 화면에 반영된다.
   - 성공하고 활성 세부 카테고리가 확인되면 `분류 완료` 배지로 바뀐다.
   - 실패하거나 신뢰 기준을 충족하지 못하면 `AI 확인 실패` 또는 `수동 확인` 배지를 유지한다.
   - 좌표 누락·폐업·중복 후보는 `승인 불가` 상태를 유지한다.
6. 자동 분류가 끝나면 `autoClassify` 쿼리를 제거해 새로고침에 의한 중복 실행을 막는다.

동기화와 AI 분류를 하나의 서버 요청으로 합치지 않는다. 공공데이터 응답 지연과 AI 순차 호출이 겹쳐 Worker 요청 제한을 초과하는 문제를 피하기 위해 두 요청으로 분리한다.

## 검수 목록 UX

- 헤더의 `다음 10곳 AI 분류` 버튼을 삭제한다.
- 선택 작업 막대에는 핵심 행동 두 개만 둔다.
  - `선택 장소 다시 분류`
  - `선택 장소 승인·공개`
- 다시 분류는 현재 선택된 후보 중 최대 10곳만 처리한다.
- 처리 결과 배너에는 처리·성공·실패·남은 수를 표시한다.
- 성공 항목은 서버 재검증 후 `분류 완료` 배지로 전환한다.
- `수동 확인` 탭에서는 분류 완료 항목이 즉시 빠진다.
- AI 실패 항목은 수동 카테고리 선택을 유지하며 오류 유형을 작은 보조 배지로 표시한다.
- Workers AI 사용량이 일일 무료 기준의 90%에 도달하면 자동 분류와 다시 분류를 모두 중단한다.

## 페이지 이동

- 동일한 페이지 이동 컨트롤을 후보 표 위와 아래에 배치한다.
- 이전·다음 버튼과 `현재 / 전체 페이지`를 표시한다.
- 검색, 지역, 공공데이터 종류, 세부업태, 카테고리, 신뢰도, 상태, 페이지 크기 쿼리를 그대로 보존한다.
- 첫 페이지에서는 이전, 마지막 페이지에서는 다음 버튼을 비활성화한다.
- 자동 분류 후 현재 페이지가 비면 유효한 마지막 페이지로 정규화한다.

## 서버 동작

- 기존 `runAi` 액션을 자동 분류와 선택 재분류가 함께 사용한다.
- 자동 분류는 후보 ID 없이 호출해 아직 성공 기록이 없는 오래된 대기 후보 10곳을 처리한다.
- 선택 재분류는 선택 ID를 전달하며 이전 실패 기록이 있어도 새 실행을 만든다.
- 성공 여부는 AI 응답만으로 결정하지 않고 기존 카테고리 검증·주소·좌표·중복 차단 규칙을 다시 적용한다.
- 부분 실패가 발생해도 성공 결과는 보존하고 목록 전체를 오류 페이지로 보내지 않는다.
- 동기화 결과에는 성공 후 이동할 검수 URL과 자동 분류 실행 여부를 명시한다.

## 상태·배지 규칙

| 조건 | 기본 배지 | 검수 목록 처리 |
| --- | --- | --- |
| AI 성공 + 활성 세부 카테고리 + 차단 사유 없음 | 분류 완료 | 수동 확인 탭에서 제외 |
| AI 실패 | AI 확인 실패 | 수동 카테고리 선택 유지 |
| AI 미실행 또는 결과 불충분 | 수동 확인 | 수동 카테고리 선택 유지 |
| 폐업·좌표 누락·중복 | 승인 불가 | 선택·승인 비활성화 |

`분류 완료`는 자동 공개를 의미하지 않는다. 장소 공개는 관리자의 `선택 장소 승인·공개` 작업 이후에만 이뤄진다.

## 오류 처리

- 동기화 실패 시 검수 목록으로 이동하지 않고 원천 오류를 동기화 화면에 표시한다.
- 자동 분류 요청 실패 시 목록은 유지하고 재시도 가능한 배너를 표시한다.
- AI JSON 검증 실패는 후보별 실패로 기록하고 나머지 후보 처리를 계속한다.
- 사용량 제한에 도달하면 배너에 제한 원인을 표시하며 분류 버튼을 비활성화한다.
- 브라우저가 자동 분류 도중 닫혀도 적재 데이터는 보존된다. 다음 검수 화면 진입에서 수동 재분류할 수 있다.

## 테스트 범위

- 동기화 성공 후 자동 분류 쿼리가 포함된 검수 URL로 이동한다.
- 검수 화면의 자동 실행은 한 번만 발생하고 쿼리를 제거한다.
- 상단 헤더 AI 버튼이 렌더링되지 않는다.
- 상단·하단 페이지 이동 링크가 같은 필터 쿼리를 보존한다.
- 선택 재분류는 10곳 제한과 AI 사용량 제한을 지킨다.
- 성공한 AI 후보는 분류 완료 상태가 되고 수동 확인 필터에서 제외된다.
- 실패 후보와 차단 후보는 공개되지 않는다.
- 기존 승인·공개, 필터, 전체 선택 동작에 회귀가 없다.

## 제외 범위

- AI가 자동으로 장소를 공개하는 기능
- Cloudflare Queue·Workflow 신규 도입
- 공공데이터 동기화 자체의 페이지 크기·타임아웃 구조 변경
- AI 분류 정확도 알고리즘 개편

동기화 타임아웃과 AI 분류 정확도 개선은 별도 작업으로 분리한다.
