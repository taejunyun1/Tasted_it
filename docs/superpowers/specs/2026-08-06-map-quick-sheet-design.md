# 지도 빠른 탐색 바텀시트 설계

## 목표

사용자가 지도와 장소 목록의 맥락을 잃지 않고 여러 장소를 빠르게 비교하도록 한다.

## 확정 구조

- 장소나 마커를 선택해도 왼쪽 검색·카테고리·목록은 그대로 유지한다.
- 선택한 장소의 핵심 정보는 지도 아래에서 올라오는 비모달 바텀시트로 표시한다.
- 시트는 장소명, 동네, 주소, 카테고리, 추천 지표, 길찾기만 우선 노출한다.
- 추천 지표는 숫자와 수평 바로 함께 표시한다. 8표 미만이면 공개까지의 진행도를 표시한다.
- 전체 장소 페이지로 이동하는 `상세 보기`는 작은 보조 링크로 낮춘다.
- 닫기 버튼은 URL의 `selected`만 제거하며 검색·카테고리·지도 범위는 보존한다.
- 다른 목록/마커를 선택하면 시트 내용과 지도 포커스가 즉시 교체된다.

## 반응형

- 데스크톱: 지도 하단 중앙의 넓고 낮은 플로팅 시트.
- 모바일: 화면 좌우 10px, 하단 10px에 고정되며 목록 패널보다 위에 표시.
- 진입 시 짧은 상승 애니메이션을 사용하고 `prefers-reduced-motion`에서는 제거한다.
