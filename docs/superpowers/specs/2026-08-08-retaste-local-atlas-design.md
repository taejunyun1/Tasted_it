# 로컬 푸드 아틀라스 지도 탐색 디자인 명세

## 목표

Re:Taste의 공개 지도 화면을 일반적인 지도 서비스나 SaaS 대시보드가 아닌, 광주·전남의 동네와 음식을 직접 기록한 `로컬 푸드 아틀라스`처럼 보이게 만든다. 사용자는 지도를 중심으로 동네와 음식 분류를 좁히고, 검수된 장소를 선택해 핵심 정보와 상세 정보를 확인한다.

## 핵심 흐름

1. 지도와 왼쪽 탐색 패널에서 동네·상호명 또는 음식 분류를 선택한다.
2. 지도 핀이나 장소 목록에서 한 곳을 선택한다.
3. 빠른 정보 패널에서 추천 지표와 주소를 확인한다.
4. 모바일에서는 상세 보기를 바텀시트로 열어 평가와 맛 특징을 확인한다.

## 시각 방향

- 밝은 종이색 배경과 짙은 감색, 숲색을 기본으로 사용한다.
- 강조색은 감귤색을 제한적으로 사용해 선택 상태와 핵심 숫자를 드러낸다.
- 카드가 겹치는 대시보드 대신 선, 여백, 색면으로 정보 단계를 구분한다.
- 모서리는 검색창과 작은 배지에만 절제해 사용한다.
- `검수 완료`는 도장이나 손글씨가 아닌 작고 단정한 상태 배지로 표시한다.
- 이모지는 데이터 식별 보조로 유지하되 장식처럼 과도하게 사용하지 않는다.

## 타이포그래피

- 기본 UI와 본문: `SUIT`, `Pretendard`, Apple SD Gothic Neo, sans-serif 순서.
- 숫자와 짧은 지표: IBM Plex Mono 계열 또는 시스템 고정폭 글꼴.
- 명조체는 사용하지 않고 크기, 굵기, 자간으로 편집 디자인의 위계를 만든다.

## 주요 화면

### 데스크톱 지도 탐색

- 탐색 목록과 지도는 좌우로 분리하며, 목록은 360~420px 범위로 제한해 지도를 더 넓게 유지한다.
- 왼쪽 패널 상단에 작은 `GWANGJU · JEONNAM FOOD ATLAS` 표식과 탐색 제목을 둔다.
- 검색, 현재 위치, 분류 선택, 결과 수, 지역별 목록이 자연스럽게 이어진다.
- 목록의 각 장소에는 순번, 장소명, 분류·동네, 검수 완료 배지, 추천 지표를 표시한다.
- 지도는 화면의 주인공으로 유지하고 빠른 정보 패널은 하단에 낮고 넓게 배치한다.

### 모바일

- 지도는 화면 전체를 사용하고 탐색 목록과 상세 정보만 지도 위 바텀 패널로 겹쳐 표시한다.
- 처음에는 지도가 최대한 보이고 지도/목록 전환부만 하단에 둔다.
- 장소를 선택하면 사진과 이름이 먼저 보이는 빠른 정보 패널을 표시한다.
- 상세 보기는 화면 아래에서 올라오는 바텀시트로 제공하며 주요 행동은 하단에 고정한다.

## 접근성과 반응형

- 본문과 상태 텍스트의 명도 대비를 확보한다.
- 색상만으로 선택이나 검수 상태를 전달하지 않고 텍스트를 함께 표시한다.
- 기존 키보드 탐색, Escape 닫기, 역할과 레이블을 유지한다.
- 760px 이하에서 지도 중심의 모바일 구조로 전환한다.
