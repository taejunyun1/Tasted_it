# 리뷰어 최근 발행 리스트 디자인

## 목적

리뷰어의 최근 발행 기록을 큰 카드 모음 대신 빠르게 훑을 수 있는 작은 리스트로 바꾼다. 기록을 다시 수정하거나 상세하게 읽는 기능은 추가하지 않는다.

## 사용자 경험

- 최근 발행의 각 항목은 한 줄 기반의 짧은 기록이다.
- 왼쪽에는 평가 상태, 가운데에는 장소명과 카테고리·맛 배지, 오른쪽에는 사진 수와 발행일을 둔다.
- 사진이 있으면 첫 사진을 작은 정사각형 썸네일로 보여 주되, 사진이 없으면 빈 썸네일 영역을 만들지 않는다.
- 장소명만 기존 `/places/:placeSlug` 상세 페이지 링크로 제공한다.
- 리스트 항목 전체에는 별도 클릭·바텀시트·모달을 제공하지 않는다.
- 링크와 버튼은 키보드 포커스와 포인터 커서를 유지한다.

## 화면 규칙

- 데스크톱: 최대 6개를 세로 리스트로 표시한다.
- 모바일: 같은 리스트를 한 열로 표시하고, 썸네일·날짜·사진 수를 한 줄에 압축한다.
- Golden Pick은 작은 텍스트 배지로만 보이며 새 색 체계는 추가하지 않는다.
- 기존 Re:Taste 녹색·연한 미스트·얇은 테두리·SUIT 계열 밀도를 유지한다.

## 데이터 및 범위

- 기존 `ReviewerHistory`의 장소명, 카테고리, 평가, 배지, 사진, Golden Pick ID, 발행일을 사용한다. 기존 장소 상세 링크를 위해 loader 조회 결과에 이미 보관된 장소 슬러그를 함께 투영한다.
- D1 스키마·R2·환경 변수·공개 사진 경로는 바꾸지 않는다.
- 기존 리뷰 발행·사진 업로드·성공 토스트 흐름은 유지한다.

## 검증

- 최근 발행이 리스트 항목과 장소 상세 링크로 렌더링된다.
- 사진이 있는 기록은 썸네일과 사진 수를 보인다.
- Golden Pick 기록은 작은 상태 배지를 보인다.
- 데스크톱과 모바일 Playwright에서 리스트와 키보드 링크 동작을 확인한다.
