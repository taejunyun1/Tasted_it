# 지도 마커 포커스·영향력 디자인 명세

## 목표

회원 지도와 카테고리 지도에서 장소 마커를 누르면 해당 좌표로 자연스럽게 이동하고 확대한다. 마커는 작은 이모지를 유지하는 Flat 스타일로 표시하며, 장소의 평가 표본 영향력을 외부 그림자로 구분한다.

## 확정 디자인

- 마커 본체는 반투명 흰색 원, 얇은 초록 계열 테두리로 표현한다.
- 내부 그라데이션과 입체 하이라이트는 사용하지 않는다.
- 이모지는 12px를 기준으로 하며 마커 본체보다 시각적으로 두드러지지 않게 한다.
- 본체 크기 차이는 최대 4px로 제한하고, 영향력은 주로 그림자 반경과 불투명도로 표현한다.
- 선택된 마커는 브랜드 초록색 2px 테두리와 낮은 불투명도의 외곽 링을 추가한다.
- 폰트 굵기는 기존 원칙대로 600 이하를 유지한다.

## 영향력 단계

영향력은 추천률이 아니라 검증된 평가 표본 수 `positive + negative`를 사용한다. 높은 추천률만으로 마커가 과도하게 강조되는 것을 방지한다.

- 기본: 0~7표 — 30px 본체, 약한 그림자
- 중간: 8~24표 — 32px 본체, 중간 그림자
- 높음: 25표 이상 — 34px 본체, 넓고 진한 그림자
- 선택: 영향력 단계와 무관하게 36px 상한, 초록 테두리와 외곽 링 적용

## 클릭 동작

1. 사용자가 마커를 클릭한다.
2. 기존 `onSelect(place.id)`를 호출해 URL 선택 상태와 왼쪽 상세 패널을 갱신한다.
3. 네이버 지도 `panTo()`로 장소 좌표를 중심에 부드럽게 이동한다.
4. 현재 줌이 16보다 낮을 때만 16으로 확대한다. 이미 더 확대된 상태는 유지한다.
5. 마커 클릭으로 발생한 첫 `idle`은 bbox 저장을 건너뛴다. 다음 사용자 직접 이동부터 기존 bbox 상태를 다시 갱신한다.

마커 클릭에만 자동 줌을 적용한다. 왼쪽 목록 선택과 검색 결과 갱신은 사용자가 보고 있던 지도 범위를 임의로 변경하지 않는다.

## 접근성과 오류 처리

- 각 마커 버튼의 `aria-label`은 기존처럼 장소명을 포함한다.
- 이모지는 장식이 아닌 카테고리 식별 정보이므로 버튼 안에 유지한다.
- 지도 SDK가 없거나 초기화되지 않은 경우 기존 오류 UI를 유지한다.
- 좌표가 유효한 공개 장소만 `PlaceSummary`에 포함되므로 클릭 시 별도 좌표 대체값을 사용하지 않는다.

## 테스트 기준

- 영향력 단계 계산을 경계값 7/8/24/25에서 단위 테스트한다.
- 클릭 포커스 정책은 줌 16 미만이면 16, 16 이상이면 현재 줌 유지로 단위 테스트한다.
- 마커 클릭 시 선택 콜백, `panTo`, 조건부 `setZoom` 호출을 컴포넌트 테스트 또는 브라우저 QA로 검증한다.
- 회원 메인에서 왼쪽 상세 패널 표시, 검색, 지도 확대/축소가 기존대로 작동하는지 회귀 QA한다.

## 제외 범위

- 추천률 색상 히트맵
- 마커 클러스터링
- 실제 사진 썸네일을 마커 내부에 표시
- 목록 클릭 시 자동 줌
