# 장소 발견형 목록 설계

## 목표

`/places`의 첫 화면을 검색창과 전체 그리드가 먼저 보이는 구조에서 추천을 먼저 탐색하는 발견형 피드로 변경한다. 사용자는 가까운 장소, Re:Taste가 추천하는 장소, 최근 Golden Pick을 순서대로 훑은 뒤 전체 장소를 검색하거나 필터링한다.

## 화면 순서

1. **내 주변 추천**: URL의 지도 중심 좌표를 기준으로 가까운 공개 장소를 최대 8개 노출한다. 중심 좌표가 없으면 기본 지도 중심을 사용하고, 위치 정확도를 과장하지 않도록 제목 아래에 기준 동네를 표시한다.
2. **Re:Taste 추천**: 공개 가능한 평가가 있는 장소를 추천률, 평가 수, 리뷰어 평가 순으로 정렬해 최대 8개 노출한다. 추천 근거는 카드에 `추천 88% · 25명 평가`처럼 표시한다.
3. **최근 Golden Pick**: 만료·철회되지 않은 Golden Pick을 최근 부여 순으로 최대 8개 노출한다. 카드에는 Golden Pick 배지와 선정일을 표시한다.
4. **전체 장소**: 이 구역에서만 검색창, 카테고리 조건, 결과 수와 전체 카드 그리드를 제공한다.

각 추천 구역은 가로 스크롤 카드 레일을 사용한다. 모바일에서는 카드 약 82vw, 데스크톱에서는 한 화면에 3~4장이 보인다. 같은 장소가 여러 추천 구역에 해당하면 앞쪽 구역에만 노출해 반복을 줄인다. 전체 장소에는 추천 구역에 나온 장소도 다시 포함한다.

## 평가 표시 규칙

- 평가는 `positive + negative`를 표본 수로 사용한다.
- 8표 미만은 추천률을 숨기고 `평가 n/8`로 표시한다.
- 8표부터 `추천 {추천률}% · {표본 수}명 평가`를 표시한다.
- 추천률은 기존 `rating-v1` 정책대로 긍정·부정에 각각 2표의 사전값을 더한 뒤 추천 비율을 반올림한다. 예를 들어 실제 6추천·2비추천은 75%가 아니라 보정된 67%로 표시한다.
- 테스트·운영 QA용 장소 표본은 0, 3, 7, 8, 12, 25, 50표 이상으로 분산한다. 추천/비추천 비율도 서로 다르게 구성해 50%, 60%, 67%, 75%, 83%, 88%, 90%대가 비교되게 한다.
- QA 데이터는 `@retaste.local` 테스트 계정의 투표로만 생성하며 실제 사용자 투표를 덮어쓰지 않는다. 반복 실행해도 같은 결과가 되는 idempotent 스크립트로 관리한다.

## 데이터와 정렬

- 공개 장소 조회는 기존 `PUBLISHED`, 대표 카테고리 조건을 유지한다.
- 거리 계산은 서버에서 Haversine 거리로 수행하고 카드에 1km 미만은 m, 그 이상은 km로 표시한다.
- 서비스 추천은 최소 8표를 충족한 장소만 대상으로 한다. 우선순위는 추천률 내림차순, 표본 수 내림차순, 이름 오름차순이다.
- Golden Pick은 활성 GRANT 이벤트만 대상으로 하며 최신 부여일 내림차순이다.
- 추천 섹션의 후보가 없으면 해당 섹션을 숨기지 않고 이유와 다음 행동이 담긴 빈 상태를 표시한다.

## 컴포넌트 경계

- `place-discovery.server.ts`: 전체 공개 장소와 Golden Pick을 받아 섹션별 후보, 거리, 중복 제거 결과를 생성한다.
- `PlaceDiscoveryRail.tsx`: 섹션 제목, 설명, 가로 카드 레일, 빈 상태를 렌더링한다.
- `PlaceCard.tsx`: 평가 표본 문구, 거리, Golden Pick 보조 정보를 선택적으로 표시한다.
- `place-list.tsx`: loader에서 데이터를 조합하고 네 개 구역의 순서만 책임진다.
- `seed-rating-qa.sql`: 정해진 QA 계정과 공개 장소에 서로 다른 평가 표본을 반복 가능하게 입력한다.

## 오류와 개인정보

- 브라우저 위치 권한은 목록 진입 시 새로 요청하지 않는다. 지도 URL이 넘긴 중심 좌표를 사용해 권한 팝업을 반복하지 않는다.
- Golden Pick이나 평가 부가 조회가 실패해도 전체 장소 탐색은 유지한다.
- 평가 QA 계정은 서비스 로그인용으로 노출하지 않고 시드 식별 용도로만 사용한다.

## 검증 기준

- 브라우저 테스트에서 `내 주변 추천 → Re:Taste 추천 → 최근 Golden Pick → 전체 장소` 순서를 검증한다.
- 검색 입력은 추천 영역 뒤에 나타나며 기존 URL 검색·카테고리·지도 복귀 조건을 보존한다.
- 단위 테스트에서 거리 정렬, 서비스 추천 정렬, 추천 영역 중복 제거, 7표/8표 공개 경계를 검증한다.
- 시드 실행 후 운영 D1에서 장소별 표본 수가 서로 다르고 카드 문구가 규칙대로 표시되는지 검증한다.
- 모바일 가로 스크롤, 키보드 포커스, 700 이상의 과도한 폰트 굵기 미사용을 확인한다.
