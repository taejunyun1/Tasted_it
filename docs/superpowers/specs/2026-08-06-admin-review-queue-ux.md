# 관리자 분류 큐 UX 정리

## 목표

관리자가 화면을 보고 다음 행동을 즉시 이해하고, AI 분류가 완료된 후보가 수동 확인 큐에 남지 않게 한다.

## 화면 결정

- 상단의 페이지별 운영 바로가기 버튼 묶음을 제거한다.
- 상단 핵심 행동은 `다음 10곳 AI 분류` 하나만 유지한다.
- 선택 작업 영역에는 `선택 장소 AI 분류`, `선택 장소 승인·공개` 두 행동만 둔다.
- 일괄 반려 사유, 선택 반려, 별도 선택 해제 버튼을 제거한다.
- 현재 페이지 선택은 선택/해제를 한 버튼에서 토글하는 보조 조작으로 표시한다.
- `자동 승인` 명칭은 실제 동작에 맞게 `분류 완료`로 변경한다. 분류 완료는 공개 완료를 뜻하지 않는다.

## 큐 상태

- AI 성공 결과가 유효하고 카테고리가 활성 상태면 `수동 확인`에서 `분류 완료`로 이동한다.
- 주소·좌표·중복 등 차단 사유가 있으면 AI 성공 여부와 무관하게 `승인 불가`에 남는다.
- AI 실패 또는 출력 검증 실패는 `수동 확인`에 남는다.
- 규칙과 AI가 안전 기준까지 일치한 후보만 `eligible=true`로 유지한다. 분류 완료와 자동 공개 안전 조건은 분리한다.
- 무선택 AI 실행은 성공 이력이 없는 후보만 오래된 순서대로 최대 10곳 처리한다. 따라서 같은 후보를 캐시로 반복하지 않고 큐가 전진한다.
