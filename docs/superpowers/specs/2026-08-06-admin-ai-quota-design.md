# 관리자 AI 분류 사용량 보호 설계

## 결정

- 외부 AI API를 추가하지 않고 기존 Cloudflare Workers AI 바인딩 `env.AI`를 사용한다.
- 하루 무료 기준은 10,000 Neurons, 서비스 차단선은 90%인 9,000 Neurons로 둔다.
- Worker가 Cloudflare 대시보드의 계정 전체 일일 사용량을 직접 조회할 수 없으므로 AI 응답의 토큰 사용량을 D1에 저장해 앱 호출분을 집계한다.
- 배포 전 사용량은 소급하지 못하므로 UI에 `앱 집계 기준`이라고 표시한다. 날짜 경계는 Cloudflare 무료 할당량과 같은 UTC 자정이다.
- 현재 모델의 공개 단가가 불명확한 경우에도 과소 집계하지 않도록 보수적인 Llama 3.1 8B 환산율(입력 25,608, 출력 75,147 Neurons/백만 토큰)을 사용한다.
- 9,000 이상이면 경고 배너를 표시하고 전체/선택 AI 분류 버튼을 비활성화한다. 서버 액션도 동일 정책을 재검증한다.

## 처리 흐름

1. 관리자 화면 로더가 오늘의 D1 집계 사용량을 읽는다.
2. AI 분류 액션은 최대 10곳만 가져온다.
3. 후보마다 캐시를 먼저 확인하고, 캐시가 없을 때만 Workers AI를 호출한다.
4. JSON 검증 실패만 한 번 재시도하며 두 호출의 사용량을 모두 합산한다.
5. 한 후보가 실패해도 다음 후보는 계속 처리한다.
6. 처리 결과와 사용량을 D1에 저장하고 성공·실패·캐시·남은 할당량을 배너로 반환한다.
7. 사용량이 9,000에 도달하면 남은 후보를 호출하지 않는다.

## 관리자 UI

- 현재 페이지의 선택 가능 후보를 최대 25곳까지 한 번에 선택하거나 모두 해제한다.
- 차단 후보는 전체 선택에서 제외한다.
- 카드형 검수 목록을 데스크톱에서는 밀도 높은 행으로 축소한다.
- 규칙 기반 추천 대표 카테고리를 기본 선택값으로 유지하고 근거/신뢰도는 접어서 표시한다.
- AI 영역에 오늘 사용량, 비율, UTC 초기화 기준을 표시한다.
- 503 등 액션 예외는 전체 오류 페이지 대신 결과 배너로 표시한다.

## 데이터

`ai_classification_runs`에 입력 토큰, 출력 토큰, 추정 Neurons, 시도 횟수를 추가한다. 캐시 재사용은 0 Neurons로 기록한다. 기존 행은 NULL이므로 오늘 집계에서 0으로 처리한다.
