# 관리자 승인·AI 처리 및 모바일 상세 바텀시트 설계

## 목표

관리자가 선택 가능한 카테고리를 실제로 승인할 수 있게 하고, AI 분류 대기시간을 줄이며, 모바일 지도와 맛집 목록의 상세 탐색을 페이지 이동 없는 바텀시트로 통일한다.

## 1. 최종 카테고리 승인

- 활성 카테고리 중 자식 카테고리가 없는 항목은 `parentId` 유무와 관계없이 최종 선택 가능한 카테고리다.
- 따라서 `치킨`, `도시락·간편식`, `기타`는 자체 ID로 승인할 수 있다.
- 자식이 존재하는 상위 그룹인 `한식`, `일식`, `카페·디저트` 등은 계속 승인할 수 없다.
- UI의 선택 가능 판정과 서버의 승인 가능 판정이 같은 순수 함수를 사용한다.
- 일괄 승인 결과에는 후보별 실패 사유를 표시한다. 실패 사유는 원시 오류 코드가 아니라 한국어 운영 문구로 보여준다.

## 2. AI 분류 성능

- 규칙 분류 신뢰도가 `HIGH`이고 활성 최종 카테고리가 존재하면 AI를 호출하지 않고 즉시 분류 완료로 기록한다.
- `MEDIUM`, `LOW`, `CONFLICT` 또는 카테고리 미확정 후보만 Workers AI로 보낸다.
- AI 대상은 최대 10곳을 유지하되 동시에 최대 3곳만 처리한다.
- 각 장소의 JSON 검증 실패 재시도는 기존 1회를 유지한다.
- 일부 요청이 실패해도 나머지 처리는 완료하며 성공·규칙 확정·실패 개수를 응답한다.
- 기존 30일 캐시는 유지하고 캐시 적중은 AI 호출 슬롯을 사용하지 않는다.
- 무료 사용량 90% 차단 정책은 유지한다.

## 3. 모바일 상세 바텀시트

### 진입 범위

- 화면 폭 760px 이하에서는 지도 마커, 지도 목록, 발견형 맛집 카드의 상세 진입을 바텀시트로 통일한다.
- 데스크톱에서는 기존 `/places/:placeSlug` 상세 페이지 이동을 유지한다.
- 모바일에서도 상세 URL은 `?place=<slug>` 형태로 현재 화면 URL에 반영해 새로고침·뒤로가기·공유가 가능해야 한다.

### 바텀시트 구조

- 우측 상단에 항상 보이는 `X` 닫기 버튼을 둔다.
- 드래그 핸들과 스크롤 가능한 본문을 제공한다.
- 이미지, 카테고리, 동네, 장소명, 주소, Golden Pick, Hidden Gem, 전체 평가와 일반회원·리뷰어 구성, Flavor Print, 주차·전화 정보를 표시한다.
- 하단 고정 액션에 `맛집지도에 추가`와 `네이버 길찾기`를 둔다.
- `맛집지도에 추가`는 기존 `savedPlaces` 저장 기능을 사용한다. 로그인 상태에서는 즉시 토글하고, 비로그인 상태에서는 로그인 후 동일 화면과 장소로 복귀한다.
- 추천·비추천도 기존 투표 action을 재사용한다.
- 닫기, 바깥 영역 누르기, Escape, 브라우저 뒤로가기로 닫을 수 있다.
- 열릴 때 본문 스크롤을 잠그고 닫힐 때 원래 카드·지도 위치와 포커스를 복원한다.

### 데이터 흐름

- 모바일 셸은 선택한 slug로 전용 resource route를 호출해 기존 상세 loader와 동일한 상세 뷰 모델을 받는다.
- 지도와 목록은 공통 `MobilePlaceDetailSheet` 컴포넌트를 사용한다.
- 저장·투표 후에는 fetcher로 상세 데이터만 다시 검증하며 전체 페이지를 이동하지 않는다.
- 로딩 중에는 시트 골격을 보여주고, 실패하면 시트 안에 재시도와 닫기 액션을 표시한다.

## 4. 접근성과 반응형

- 바텀시트는 `role="dialog"`, `aria-modal="true"`, 장소명을 포함한 접근 가능한 이름을 가진다.
- 열릴 때 닫기 버튼으로 포커스를 이동하고 포커스를 시트 내부에 유지한다.
- 761px 이상에서 모바일 상세 파라미터로 접근하면 정식 상세 페이지로 이동한다.
- 모바일의 긴 장소명과 작은 화면에서도 닫기·저장 액션이 가려지지 않아야 한다.

## 5. 검증

- 자식 없는 상위 카테고리 승인 성공과 자식 있는 상위 그룹 거절을 통합 테스트한다.
- 승인 실패 사유의 한국어 매핑을 단위 테스트한다.
- 규칙 HIGH 후보가 AI 호출 없이 완료되는지, 애매한 후보의 동시 실행 수가 3을 넘지 않는지 테스트한다.
- 지도와 목록 양쪽에서 모바일 상세 시트 열기·닫기·뒤로가기·저장·비로그인 복귀를 E2E 테스트한다.
- 데스크톱 상세 페이지 이동 회귀를 검증한다.
