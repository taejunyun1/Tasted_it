# Reviewer Management Design

작성일: 2026-08-05
상태: 확정 설계

## 1. 목적과 범위

일반 회원이 리뷰어 승급을 신청하고, 관리자가 근거와 이력을 확인해 승인·반려하며, 승인된 리뷰어의 공개 프로필과 활동 상태를 관리한다.

이번 단위에는 리뷰어 전용 평가, 리뷰어 팔로우, Golden Pick, 사용자 장소 제안 입력 화면은 포함하지 않는다. 장소 제안 기능이 완성되기 전에도 초기 리뷰어를 운영할 수 있도록 관리자 예외 승인을 제공한다.

## 2. 접근 방식

### 채택안: 신청 이력과 공개 프로필 분리

- `reviewer_applications`는 신청 당시 의견서, 전문 분야, 지역, 자격 수치와 관리자 결정을 보존한다.
- `reviewer_profiles`는 승인 후 공개되는 현재 프로필과 ACTIVE, DORMANT, SUSPENDED 상태를 보존한다.
- `users.role`은 실제 권한을 나타낸다. ACTIVE일 때만 REVIEWER이며, 휴면·정지 시 USER로 되돌린다.

역할 컬럼만 직접 변경하는 방식은 신청·반려·휴면 이력이 남지 않아 사용하지 않는다. 장소 제안 전체를 동시에 구현하는 방식은 검수·중복·지도 검색까지 별도 제품 단위이므로 이번 범위에서 분리한다.

## 3. 신청 자격과 초기 운영

- 기본 승인 자격은 관리자가 승인한 장소 제안 10곳 이상이다.
- 신청 자체는 10곳 미만이어도 가능하다. 화면에 현재 승인 수와 부족 수량을 명확히 표시한다.
- 관리자는 10곳 미만 신청을 일반 승인할 수 없다.
- 초기 리뷰어 영입 등 운영상 필요하면 `예외 승인`을 사용할 수 있다. 예외 사유는 필수이며 감사 로그에 남긴다.
- 장소 제안 기능이 구현되기 전 승인 제안 수는 0으로 계산한다. 향후 `place_suggestions`의 APPROVED 건수를 동일 서비스 인터페이스에 연결한다.

## 4. 신청 데이터

회원은 다음 항목을 제출한다.

- 본인의 맛집 선정 기준을 설명하는 의견서: 100~1,000자
- 직업 또는 활동 소개: 최대 80자
- 취향 방향: 최대 200자
- 활동 지역: 광주 또는 전남
- 전문 카테고리: 활성 대분류 중 1~3개

한 회원은 동시에 하나의 진행 중 신청만 가질 수 있다. 반려 후에는 새 신청을 제출할 수 있으며 이전 신청 이력은 유지한다.

## 5. 상태와 권한

### 신청 상태

- APPLIED: 회원 제출 완료
- REVIEWING: 관리자가 검토 시작
- APPROVED: 승인 완료
- REJECTED: 반려 완료

### 프로필 상태

- ACTIVE: 공개 프로필 노출, 사용자 역할 REVIEWER
- DORMANT: 공개 프로필에는 휴면 표시, 사용자 역할 USER
- SUSPENDED: 공개 목록과 프로필 비노출, 사용자 역할 USER

관리자는 ACTIVE 리뷰어를 휴면 또는 정지로 전환하고, 휴면 리뷰어를 다시 활성화할 수 있다. 정지 해제는 관리자 재활성화로 처리하며 사유를 남긴다.

## 6. 휴면 규칙

- 마지막 리뷰어 활동일로부터 90일이 지나면 휴면 대상이다.
- 리뷰어 전용 활동 기능이 완성되기 전에는 승인일을 마지막 활동일로 사용한다.
- 관리자 화면에 휴면 대상 수를 표시하고 `휴면 대상 반영`으로 일괄 전환한다.
- 자동 스케줄러 연결은 추후 운영 자동화 단계에서 추가한다.

## 7. 화면

### `/reviewer/apply`

- 로그인 회원의 현재 역할, 최신 신청 상태, 승인 장소 제안 수를 표시한다.
- 진행 중 신청이 있거나 이미 ACTIVE 리뷰어면 중복 제출을 막는다.
- 의견서, 직업, 취향 방향, 활동 지역, 전문 카테고리를 입력한다.

### `/admin/reviewers`

- 신청 대기, 검토 중, 활성, 휴면, 정지, 반려 탭을 제공한다.
- 이메일·이름 검색과 상태 필터를 제공한다.
- 신청 의견서, 승인 제안 수, 전문 분야, 활동 지역, 신청일을 한 목록에서 확인한다.
- 검토 시작, 승인, 예외 승인, 반려, 휴면, 정지, 재활성화 작업을 제공한다.

### `/reviewers/:slug`

- ACTIVE와 DORMANT 프로필만 공개한다.
- 표시 이름, 직업, 취향 방향, 활동 지역, 전문 카테고리, 가입일을 표시한다.
- SUSPENDED 프로필은 404로 처리한다.

## 8. 오류와 감사

- 신청 입력 오류는 같은 화면에서 필드 오류로 표시한다.
- 일반 승인의 10곳 요건 미달, 중복 진행 신청, 잘못된 상태 전이는 서버에서 거부한다.
- 승인·예외 승인·반려·휴면·정지·재활성화는 `admin_audit_logs`에 이전 상태와 이후 상태를 기록한다.
- 관리자 반려와 정지 사유는 필수다.

## 9. 테스트와 완료 기준

- 100자 미만 의견서와 전문 카테고리 0개 또는 4개 이상을 거부한다.
- 진행 중 신청 중복을 거부하고 반려 후 재신청은 허용한다.
- 10곳 미만 일반 승인을 거부하고 사유가 있는 예외 승인은 허용한다.
- 승인 시 프로필과 REVIEWER 역할이 생성된다.
- 90일 휴면 전환 시 역할이 USER가 되며, 재활성화 시 REVIEWER로 복구된다.
- 정지 프로필은 공개되지 않는다.
- 회원·관리자·공개 프로필 흐름을 데스크톱과 모바일에서 검증한다.

## 10. 제품 가이드 반영

리뷰어 시스템 단계는 다음 순서로 세분화한다.

1. 이번 단위: 신청·관리자 심사·공개 프로필·휴면/정지 상태
2. 장소 제안 단위: 실제 승인 제안 수 자동 연결
3. 평가 고도화 단위: 리뷰어 전용 평가와 신뢰 지표
4. 개인화 단위: 리뷰어 팔로우와 알림
