# 자동 분류·일괄 검수 구현 계획

**목표:** 영업 중 후보를 상호명과 공공데이터 업태로 자동 분류하고, 높은 신뢰도의 안전한 후보를 카테고리별로 묶어 최대 25곳씩 일괄 승인한다.

## Task 1: 자동 분류

- 상호명 키워드와 원천 세부업태를 각각 판정
- 두 신호 일치 시 `HIGH`, 하나만 구체적이면 `MEDIUM`, 기본값만 있으면 `LOW`, 서로 다르면 `CONFLICT`
- 주소에서 동·읍·면을 추출
- 카테고리 slug, 근거, 신뢰도를 반환하는 순수 함수 테스트

## Task 2: 일괄 승인 안전성

- `OPEN + PENDING`, 정상 좌표, 주소·상호·동네, 활성 소분류, 높은 신뢰도 검사
- 같은 상호·주소의 기존 장소 및 요청 내부 중복 제외
- 최대 25개 제한
- 개별 승인 서비스를 재사용하고 성공·제외·실패 결과 반환

## Task 3: 어드민 UI

- `/admin/candidates/bulk` 추가
- 추천 대분류·소분류별 그룹, 후보 수, 신뢰도 근거 표시
- 안전 후보만 기본 선택
- 개별 선택 해제와 카테고리 그룹 전체 선택
- 보통·낮음·충돌은 개별 검수 링크 제공
- 승인 전 최종 건수와 공개 동작 명시

## Task 4: 검증과 배포

- 단위·D1 통합·타입·빌드·브라우저 테스트
- PR diff 검토, squash merge, main 배포
